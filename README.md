# SDET in Kannada

A free, responsive learning website for people learning software testing and test automation in Kannada.

## Website

Visit the live site: <https://raghuvn1999.github.io/sdet-in-kannada/>

## Features

- Kannada and English language toggle
- Courses for testing fundamentals, Java, Selenium, API testing, Git/CI/CD, and framework design
- Course search, level filters, lesson checklists, favourites, and saved progress
- Searchable SDET interview questions
- SDET and automation job links
- Light and dark themes
- Responsive layout for desktop and mobile
- Resume the next unfinished course from the course dashboard
- Installable progressive web app with offline app-shell support on compatible browsers

Progress and favourites are saved in the browser on the visitor's device using `localStorage`.

## Run locally

Open `index.html` in a web browser. The site is static and does not require a server or package installation.
